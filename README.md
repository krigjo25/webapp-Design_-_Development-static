# WebApp Design & Development (2014)

This repository holds the original 2009 web application I built as my first foray into web development, now modernized by migrating the codebase to TypeScript while retaining a built with vanilla HTML, SASS, and TypeScript.

---

## Tech Stack

- **HTML5** – Semantic markup and structure.
- **TypeScript (ES2024)** – Core application logic.
- **Git** – Version control (with GPG‑signed commits).
- - **SASS** – Custom design system, glassmorphism, dark mode, micro‑animations.
- **Optional Framework** – If you later scaffold with Vite/Next.js, the stack can expand to include those tools.
